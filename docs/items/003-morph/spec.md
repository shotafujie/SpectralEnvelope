# 仕様書: 2 つの録音の包絡モーフィング

- アイテムID: `003-morph`
- 関連ロードマップ項目: なし（001 の要件 §10 の拡張候補）
- 関連ADR: なし
- 作成日: 2026-09-18
- 前提: `001-envelope-jig` の仕様（パラメータ・加工・UI）

## 目的

分解済みの録音 A の包絡に、別の録音 B の包絡を比率 α で混ぜて再合成し、「包絡だけが B に近づくと声はどう変わるか」を聴けるようにする。

## スコープ

### やらないこと

- DTW 等による内容に沿った時間対応付け（時間は線形に伸縮するだけ）
- B の fo・ap の利用（再合成は常に A の fo・ap）
- 3 つ以上の録音の混合
- 保持件数（10 件）の変更

### やること

- パラメータ `morph` の追加（API）
- 分解済み録音の一覧から「現在の録音（A）」と「混ぜる相手（B）」を選ぶ UI、混合比スライダー、相手の包絡の表示

## 共通の定義

- **N_A / N_B** = A / B のフレーム数
- **伸縮後の B** = A のフレーム i に対し、B の位置 `p = i · (N_B − 1) / (N_A − 1)`（N_A = 1 のとき p = 0）で、B の log_sp をフレーム方向に線形補間した値

## 仕様

### API

- **SPEC-400** `params` は `morph`（`{"id": <B の id>, "ratio": <α>}`）を受け付け、`morph` を省略したときの結果は 001 の仕様どおり（混合なし）である
- **SPEC-401** `morph.ratio` は 0.0〜1.0 にクランプされる
- **SPEC-402** `morph.ratio` が 0 のとき、`/api/envelope` の `modified_db` と `/api/synthesize` の出力は `morph` 省略時と同一である
- **SPEC-403** 混合後の log_sp は、フレーム i ごとに `(1 − α) · (A の log_sp) + α · (伸縮後の B の log_sp)` である
- **SPEC-404** `morph.ratio` が 1 で他のパラメータが初期値のとき、`modified_db` は伸縮後の B の dB 表示値と一致する（差 1e-6 以内）
- **SPEC-405** 加工は morph → formant → smooth → tilt → bands の順に適用される
- **SPEC-406** `morph` を指定しても、再合成に使う fo と ap は A のもの（fo は A の fo × pitch）である
- **SPEC-407** `morph` を指定しても、`/api/synthesize` の出力のサンプル数は A の元音のサンプル数と一致する
- **SPEC-408** `morph.id` が保持されていないとき、`/api/envelope` と `/api/synthesize` は 404 を返す
- **SPEC-409** `morph` を指定したとき、`/api/envelope` の応答の `partner_db` は、指定フレームに対応する伸縮後の B の dB 表示値（1025 要素）である
- **SPEC-410** `morph` を省略したとき、`/api/envelope` の応答の `partner_db` は `null` である
- **SPEC-411** `morph.id` に A 自身の `id` を指定しても受け付け、N_A = N_B なので結果は `morph` 省略時と一致する（差 1e-6 以内）

### UI

- **SPEC-420** 「現在の録音」と「混ぜる相手」の 2 つの選択欄があり、分解済みの録音が分解した順に並ぶ。各項目のラベルは通し番号・入力元（「録音」またはファイル名）・長さ（秒）を含む
- **SPEC-421** 新しく分解が完了すると、その録音が両方の選択欄の末尾に追加され、「現在の録音」がそれに切り替わる
- **SPEC-422** 「現在の録音」を切り替えると、フレームスライダーの範囲と値（その録音の `voiced_frames` の中央）、無声表示、グラフが切り替わり、以降の API 呼び出しと元音再生はその録音の `id` を使う
- **SPEC-423** 「混ぜる相手」の先頭は「なし」で初期値もそれであり、「なし」のとき API の `params` に `morph` は含まれない
- **SPEC-424** 混合比スライダー（name `mix`）の範囲は 0〜1、刻み 0.01、初期値 0 で、隣の数値表示が追従する
- **SPEC-425** 相手を選んでいるとき、envelope 要求と synthesize 要求の `params.morph` は `{"id": <相手の id>, "ratio": <mix の値>}` である
- **SPEC-426** 相手の選択または mix の変更から 300ms 後に、envelope 要求が 1 回出る（001 のパラメータ変更と同じ 300ms デバウンス）
- **SPEC-427** 相手を選んでいるとき、グラフに相手の包絡線（`partner_db`、元包絡・加工後包絡と異なる色の破線）が描かれ、「なし」のときは描かれない
- **SPEC-428** 「すべてリセット」とプリセットは mix を 0 に戻し、「混ぜる相手」の選択は変えない
- **SPEC-429** mix スライダーをダブルクリックすると 0 に戻る
- **SPEC-430** 選択欄の録音は最新 10 件までで、11 件目が追加されると最も古いものが両方の選択欄から消え、それが相手に選ばれていた場合は「なし」になる

## 前提・依存

- サーバーの保持上限（10 件）は 001 の SPEC-013 のまま。UI の一覧の上限はこれに合わせる
