- アイテムID: `004-gain-curve`
- 仕様書: `docs/items/004-gain-curve/spec.md`

## テスト方針

| レベル | 対象 | 置き場所 |
|---|---|---|
| ユニット | ゲインカーブ関数、パラメータ解釈、加工順序 | `tests/test_curve.py` |
| 統合 | `/api/envelope`・`/api/synthesize` の `curve` | `tests/test_curve.py` |
| E2E | ハンドルとドラッグ | `tests/e2e/test_curve_ui.py` |

- C(f) の期待値はテスト側で `np.interp(log2(f), log2(f_j), c)` として独立に計算する（np.interp は範囲外で端の値を返す）
- E2E の観測点: `circle.curve-point`（`data-index`、`data-gain`、`cx`、`cy`）、`#curve-line`（path）、`#curve-readout`、`#graph` の `data-plot-left/right/top/bottom`
- ドラッグは `page.mouse` で行う。SVG 座標とクライアント座標の変換は、テスト側で `#graph` の `getScreenCTM()` を使って求める

## テストケース

### SPEC-500 curve の受け付けと既定値

- **TC-500-1** パラメータ解釈に {} → `curve` が 0 の 20 要素
- **TC-500-2** envelope で `curve` 省略 → `curve` 全 0 指定と同じ `modified_db`

### SPEC-501 形式不正は 422

- **TC-501-1** 要素数 19 で envelope → 422
- **TC-501-2** 文字列を含めて synthesize → 422
- **TC-501-3** 要素数 21 でパラメータ解釈 → バリデーションエラー

### SPEC-502 クランプ

- **TC-502-1** 先頭 2 要素が 20 と −20 → 12 と −12、その他はそのまま

### SPEC-503 ゲインの加算

- **TC-503-1** 関数に乱数の curve（±12 の一様乱数）→ 加工前後の dB 差が全ビンで独立計算した C(freq) と一致（1e-9）
- **TC-503-2** API: curve 全 +6 → `modified_db` − `original_db` が全ビンで 6（1e-6）

### SPEC-504 制御点での値と区間の線形性

- **TC-504-1** 関数を f_j で評価 → c_j と一致（1e-9）。f_j と f_(j+1) の幾何平均で評価 → (c_j + c_(j+1)) / 2
- **TC-504-2** 0Hz と 30Hz → c_0、21000Hz と 22050Hz → c_19

### SPEC-505 加工順序

- **TC-505-1** 関数で morph + formant + smooth + tilt + bands + curve の一括適用 == この順の逐次適用
- **TC-505-2** curve を formant より前に適用した結果とは一致しない

### SPEC-506 全フレーム共通、fo・ap 不変

- **TC-506-1** 乱数の curve で synthesize → 合成に渡る sp の全フレームで、`curve` 省略時の sp との dB 差が C(freq) と一致（1e-6）
- **TC-506-2** 同条件で、合成に渡る fo と ap が `curve` 省略時と要素単位で一致

### SPEC-510 ハンドルの x 位置

- **TC-510-1** ハンドルが 20 個あり、ハンドル j の cx が `left + (right − left) · log(f_j / 50) / log(441)` と 0.01 以内で一致

### SPEC-511 ハンドルの y 位置

- **TC-511-1** 初期状態 → 全ハンドルの cy がプロット上下中央
- **TC-511-2** ハンドル 7 をドラッグしてゲイン g にした後 → cy == 中央 − g · (bottom − top) / 70（0.01）

### SPEC-512 ドラッグでのゲイン設定

- **TC-512-1** ハンドル 7 を +6 dB に相当する y までドラッグ → `data-gain` が 6.0 ±0.1、他のハンドルは 0
- **TC-512-2** ハンドル 3 をプロット上端より上までドラッグ → 12.0、ハンドル 15 を下端より下まで → −12.0
- **TC-512-3** ドラッグ後の `data-gain` は小数第 1 位までの値（10 倍が整数）

### SPEC-513 横方向の移動は無視

- **TC-513-1** ハンドル 10 を右に 120px・上に移動 → ハンドル 10 の cx は変わらず `data-gain` が正、ハンドル 11 以降は 0

### SPEC-514 ゲイン線の追従

- **TC-514-1** ドラッグ中（ボタンを押したまま移動した直後）→ `#curve-line` の d にハンドルの現在の (cx, cy) が含まれる。離した後も同様

### SPEC-515 ドラッグ中の数値表示

- **TC-515-1** ハンドル 7 をドラッグ中 → `#curve-readout` が表示され、`round(f_7)` Hz と現在のゲイン（小数 1 桁、符号付き）を含む

### SPEC-516 デバウンスと送信内容

- **TC-516-1** 分解後にハンドルを 5 段階に分けてドラッグして離す → 最後の移動から 0.29 秒以上後に envelope 要求が 1 件、その `params.curve` == 画面の 20 個の `data-gain`
- **TC-516-2** 2 つのハンドルを順に動かす → 最後の要求の `params.curve` の該当 2 要素が画面の値で、他は 0

### SPEC-517 合成要求の curve

- **TC-517-1** ハンドルを動かして加工音 → synthesize 要求の `params.curve` == 画面の 20 個の `data-gain`

### SPEC-518 ダブルクリックで 0

- **TC-518-1** ハンドル 7 を動かした後にダブルクリック → `data-gain` が 0、cy が中央

### SPEC-519 リセットとプリセット

- **TC-519-1** 3 つのハンドルを動かす → すべてリセット → 全ハンドル 0
- **TC-519-2** 同じくハンドルを動かしてからプリセット 5 種それぞれ → 毎回全ハンドル 0

### SPEC-520 分解前でも操作できる

- **TC-520-1** ページ読み込み直後 → ハンドル 20 個が表示され、ハンドル 7 のドラッグで `data-gain` が 0 以外になる。envelope 要求は出ない
