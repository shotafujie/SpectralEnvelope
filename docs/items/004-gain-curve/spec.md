# 仕様書: ドラッグで描くゲインカーブ

- アイテムID: `004-gain-curve`
- 関連ロードマップ項目: なし（001 の要件 §10 の拡張候補）
- 関連ADR: なし
- 作成日: 2026-09-18
- 前提: `001-envelope-jig`、`003-morph` の仕様

## 目的

包絡グラフ上の制御点をマウスで上下に動かして任意の dB ゲインカーブを作り、全フレームに加えて再合成する。
「この帯域を持ち上げる/削るとこう聴こえる」を、バンドゲインより細かく直接試せるようにする。

## スコープ

### やらないこと

- 特定フレームだけの包絡の描き換え（ゲインは全フレーム共通）
- 制御点の追加・削除・横方向の移動（点の数と周波数は固定）
- タッチ操作・キーボード操作での編集
- ゲインカーブのプリセット・保存

### やること

- パラメータ `curve` の追加（API）
- グラフ上の制御点ハンドルとドラッグ操作

## 共通の定義

- **制御点** j = 0〜19 の周波数 `f_j = 50 · 400^(j/19)` Hz（50Hz〜20000Hz を対数等間隔に 20 点）
- **ゲインカーブ C(f)** = 制御点の値を log2(f) 上で線形補間した値。f < 50Hz では点 0 の値、f > 20000Hz では点 19 の値

## 仕様

### API

- **SPEC-500** `params` は `curve`（20 要素の数値配列、単位 dB）を受け付け、省略時は全要素 0 として扱われる
- **SPEC-501** `curve` の要素数が 20 でないとき、または数値でない値を含むとき、API は 422 を返す
- **SPEC-502** `curve` の各要素は −12.0〜+12.0 にクランプされる
- **SPEC-503** `curve` = [c_0, …, c_19] のとき、各ビンの dB 表示値に C(freq) が加算される
- **SPEC-504** C(f_j) は c_j と一致し、隣り合う制御点の間では log2(f) に対して線形である
- **SPEC-505** 加工は morph → formant → smooth → tilt → bands → curve の順に適用される
- **SPEC-506** `curve` はすべてのフレームに同じゲインを加え、fo と ap は変えない

### UI

- **SPEC-510** グラフ上に 20 個の制御点ハンドルがあり、ハンドル j の x 位置はグラフ横軸（50Hz〜22050Hz の対数スケール）での f_j の位置である
- **SPEC-511** ゲイン g のハンドルの y 位置は、プロット領域の上下中央から `g × (プロットの高さ / 70)` だけ上である（0 dB が中央、上が正）
- **SPEC-512** ハンドルを縦にドラッグすると、そのハンドルのゲインはポインタの y 位置に対応する値（y 位置の式の逆算）を 0.1 dB に丸め、±12 でクランプした値になる
- **SPEC-513** ハンドルを横方向に動かしても、ハンドルの x 位置とどの制御点かは変わらない
- **SPEC-514** 20 個のハンドルを結ぶゲイン線が描かれ、ドラッグ中もハンドルの位置に追従する
- **SPEC-515** ドラッグ中は、操作中の制御点の周波数とゲインが数値で表示される
- **SPEC-516** ゲインが変わると、最後の変更から 300ms 後に envelope 要求が 1 回出て、その `params.curve` は画面上の 20 個のゲインと一致する
- **SPEC-517** 加工音の synthesize 要求の `params.curve` は、画面上の 20 個のゲインと一致する
- **SPEC-518** ハンドルをダブルクリックすると、その制御点のゲインは 0 に戻る
- **SPEC-519** 「すべてリセット」とプリセットは、すべての制御点のゲインを 0 に戻す
- **SPEC-520** 分解前（グラフに包絡が無い状態）でもハンドルは表示され、ドラッグでゲインを設定できる
