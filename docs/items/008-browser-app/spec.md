# 仕様書: ブラウザだけで動くアプリ（Worker・保持・デコード・画面）

- アイテムID: `008-browser-app`
- 関連ロードマップ項目: なし（`docs/roadmap.md` は未作成）
- 関連ADR: `docs/adr/ADR-0001-browser-world-engine.md`
- 作成日: 2026-09-21

## 目的

006 のエンジンと 007 の DSP を Web Worker に載せ、分解結果の保持・音声のデコード・画面の操作を
ブラウザ内で完結させる。v0.1.0 の HTTP API を使わずに、同じ操作ができる状態にする。

このアイテムの完了時点で、静的な配信だけでアプリが動く（配信の仕組みそのものは 009）。

## スコープ

### やること

- Web Worker 上で動くエンジン（006 + 007）と、画面から呼ぶアダプタ
- 分解結果の保持（最大 10 件、LRU、id の発行、Float32 での保持）
- 音声のデコード（録音とファイル、44.1kHz モノラル化、長さの上限と下限）
- 画面の差し替え（`fetch("/api/...")` をアダプタ呼び出しへ）
- 再生（元音・加工音とも、WAV を作らず AudioBuffer で鳴らす）
- E2E テストの移行（観測点をネットワーク要求からアダプタへ）

### やらないこと

- **分解・再合成そのもの** → 006
- **DSP の計算内容** → 007
- **CI と GitHub Pages への配信、Pixel での実機計測** → 009
- **v0.1.0 の HTTP サーバー（`jig/server.py`）の変更**。照合用データの生成器として凍結したまま残す
- **画面の見た目の作り直し**。既存の `jig/index.html` の構造と文言を引き継ぐ。変えるのは、エンジンの呼び出し方と、そこから生じる表示だけ
- **新しい加工やパラメータの追加**

## 共通の定義

- **エンジン** = 006 の `createEngine()` が返すもの。Worker の中だけに存在する
- **アダプタ** = 画面がエンジンを使うための唯一の窓口。`window.engine` として公開する。実装は Worker 越しの呼び出しで、すべて Promise を返す
- **分解結果** = 1 回の分解で得た f0 / sp / ap と、元の音声サンプル、入力元の表示名、長さ
- **入力元の表示名** = 録音なら「録音」、ファイルならそのファイル名
- **情報** = 分解結果から画面に渡す値の組: `{ id, fs, fftSize, duration, frames, f0Mean, voicedFrames, source }`
- **params** = 007 と同じ。ただし `morph` は `{ id, ratio }`（相手を id で指す）
- **dB 値・包絡差**などの計算に関する語は 001 / 006 / 007 と同じ

## 仕様

### アダプタ（画面とエンジンの境界）

- **SPEC-900** アダプタは `analyze` / `envelope` / `synthesize` / `original` / `list` の 5 つの関数を持ち、すべて Promise を返す
- **SPEC-901** `analyze(data, source)` は、音声のバイト列 `data` をデコードして分解し、情報に解決される
- **SPEC-902** `envelope(id, frame, params)` は、`{ freq, originalDb, modifiedDb, partnerDb }` に解決される（中身は 007 の SPEC-840〜846 と同じ）
- **SPEC-903** `synthesize(id, params)` は、再合成した音のサンプル（Float32Array、44.1kHz モノラル）に解決される
- **SPEC-904** `original(id)` は、その分解結果の元の音声サンプル（Float32Array）に解決される
- **SPEC-905** `list()` は、保持している分解結果の情報を、分解した順に並べた配列に解決される
- **SPEC-906** アダプタの呼び出しは、すべて Worker の中で実行される。分解の間、メインスレッドは止まらない（分解中も 100ms ごとのタイマーが 3 回以上動く）
- **SPEC-907** `envelope` の呼び出しが前の `envelope` の完了前に届いたとき、古い方の Promise は `superseded` を理由に拒否され、新しい方だけが結果を返す
- **SPEC-908** `synthesize` と `analyze` は、前の呼び出しの完了を待ってから実行される（取り消さない）
- **SPEC-909** アダプタは、エンジンの読み込みが終わる前に呼ばれても、読み込みを待ってから実行する

### 保持

- **SPEC-910** 分解結果の `id` は 8 文字の小文字 16 進文字列で、分解のたびに異なる値になる
- **SPEC-911** 保持は最大 10 件で、11 件目を分解すると最も古い id は以後の呼び出しで `not_found` になる
- **SPEC-912** 10 件目までは、どの id も `envelope` / `synthesize` / `original` が成功する
- **SPEC-913** 保持していない id を指定したとき、`envelope` / `synthesize` / `original` は `not_found` を理由に拒否される
- **SPEC-914** `params.morph.id` が保持されていないとき、`envelope` と `synthesize` は `not_found` を理由に拒否される
- **SPEC-915** 保持する sp と ap は Float32 に落とす。f0・時刻・元の音声サンプルは Float64 のまま保持する
- **SPEC-916** 10 秒の分解結果を 10 件保持したとき、sp と ap の保持量の合計は 170MB 未満である
- **SPEC-917** Float32 で保持した sp を使って再合成した音は、Float64 のまま保持した場合の音と、全サンプルで絶対差 1e-6 以内で一致する
- **SPEC-918** Float32 で保持した sp から作った `modifiedDb` は、Float64 のまま保持した場合と全ビンで 1e-3 dB 以内で一致する

### 音声のデコード

- **SPEC-920** デコードは、任意のサンプリング周波数・チャンネル数の音声を 44100Hz モノラルにする
- **SPEC-921** デコード後の音声が 10.0 秒を超えるとき、先頭 10.0 秒だけを分解し、情報の `duration` は 10.0 になる
- **SPEC-922** デコード後の音声が 1.0 秒未満のとき、`analyze` は `too_short` を理由に拒否される
- **SPEC-923** 音声としてデコードできないデータを渡したとき、`analyze` は `decode_failed` を理由に拒否される
- **SPEC-924** 情報の `duration` は、デコード後のサンプル数を 44100 で割った秒数である
- **SPEC-925** 情報の `fs` は 44100、`fftSize` は 2048 である
- **SPEC-926** 情報の `frames` は、分解で得た f0 の要素数と一致する
- **SPEC-927** 情報の `voicedFrames` は、f0 > 0 のフレーム番号を昇順に並べた配列と一致する
- **SPEC-928** 情報の `f0Mean` は、f0 > 0 のフレームの f0 の算術平均である（有声フレームが無いときは 0）
- **SPEC-929** 情報の `source` は、`analyze` に渡した入力元の表示名と一致する

### 画面: 録音

- **SPEC-930** 録音ボタンを押すと録音が始まり、録音中は経過秒数が表示されて増えていく
- **SPEC-931** 録音中に録音ボタンを押すと録音が止まり、録音データが自動で `analyze` に渡される
- **SPEC-932** `analyze` の呼び出しから完了までの間、録音ボタンは無効になる
- **SPEC-933** 録音開始から 10 秒経つと、録音は自動で停止して `analyze` に渡される
- **SPEC-934** 分解後に再度録音すると、以降の呼び出しは新しい id を使う
- **SPEC-935** 分解が一度も完了していない間、元音・加工音ボタンは無効である
- **SPEC-936** 分解の実行中は、進行中であることが画面に表示され、完了すると消える
- **SPEC-937** マイクを取得できなかったとき、エラー表示領域にメッセージが表示される

### 画面: ファイルの読み込み

- **SPEC-940** 「ファイルを開く」ボタンがあり、ファイル選択の受け付け種別は `audio/*` と `.wav` である
- **SPEC-941** ファイルを選ぶと、その内容が `analyze` に渡され、入力元の表示名はファイル名になる
- **SPEC-942** ファイルの分解が完了すると、録音の分解完了時と同じく、フレームスライダー・グラフ・元音/加工音ボタンが有効になり、以降の呼び出しは新しい id を使う
- **SPEC-943** ファイルの分解中は、「ファイルを開く」ボタンと録音ボタンが無効になる
- **SPEC-944** 録音中は「ファイルを開く」ボタンが無効である
- **SPEC-945** ファイルの分解が拒否されたとき、エラー表示領域にメッセージが出て、それ以前の分解結果があれば以降の呼び出しはその id を使い続ける
- **SPEC-946** 同じファイルを続けて 2 回選んでも、2 回とも `analyze` が呼ばれる

### 画面: 包絡グラフ

- **SPEC-950** 分解完了後、グラフに元包絡（グレーの線）と加工後包絡（グレー以外の色で、元包絡より太い線）が描かれる
- **SPEC-951** グラフの横軸は対数スケールで、左端が 50Hz、右端が 22050Hz である（周波数 f の x 位置は `log(f/50)/log(22050/50)` に比例）
- **SPEC-952** グラフの縦軸の上端は表示フレームの元包絡（50Hz 以上）の最大 dB + 5、下端はそこから 70dB 下である
- **SPEC-953** グラフには 500 / 1500 / 4000Hz の位置に縦線が描かれる
- **SPEC-954** 相手を選んでいるとき、グラフに相手の包絡線（`partnerDb`、元包絡・加工後包絡と異なる色の破線）が描かれ、「なし」のときは描かれない

### 画面: フレーム選択

- **SPEC-955** フレームスライダーの範囲は 0〜`frames` − 1 である
- **SPEC-956** 分解完了直後のフレームスライダーの値は `voicedFrames` の中央の要素（添字 `長さ ÷ 2` の整数部）である
- **SPEC-957** 無声フレーム（`voicedFrames` に無いフレーム）を選ぶと、無声である旨の表示が出て、有声フレームに戻すと消える
- **SPEC-958** フレームスライダーを変えると、デバウンス後に選んだフレームで `envelope` が呼ばれる

### 画面: パラメータ操作

- **SPEC-960** スライダーの 範囲・刻み・初期値 は formant 0.60〜1.60・0.01・1.00、tilt −12.0〜+12.0・0.1・0.0、bands 4 本 各 −12.0〜+12.0・0.1・0.0、smooth 0〜80・1・0、pitch 0.50〜2.00・0.01・1.00 である
- **SPEC-961** 各スライダーの隣の数値表示は、スライダーの現在値に追従する
- **SPEC-962** スライダーをダブルクリックすると、そのスライダーは初期値に戻る
- **SPEC-963** 「すべてリセット」ボタンを押すと、全パラメータスライダーが初期値に戻る
- **SPEC-964** パラメータを連続して変えている間は `envelope` が呼ばれず、最後の変更から 300ms 後に 1 回だけ呼ばれる
- **SPEC-965** パラメータを変えても `synthesize` は呼ばれない
- **SPEC-966** smooth スライダーで 1〜9 を選んだとき、`envelope` と `synthesize` の要求では 10 として扱われる
- **SPEC-967** プリセットボタンを押すとスライダーが次の値になり、記載の無いパラメータは初期値になる: 素通し（すべて初期値）、子供っぽく（formant 1.25, pitch 1.15）、太く（formant 0.85, tilt −3.0）、こもる（bands [+4, 0, −6, −10]）、のっぺり（smooth 16）

### 画面: ゲインカーブ

- **SPEC-970** グラフ上に 20 個の制御点ハンドルがあり、ハンドル j の x 位置はグラフ横軸での f_j の位置である
- **SPEC-971** ゲイン g のハンドルの y 位置は、プロット領域の上下中央から `g × (プロットの高さ ÷ 70)` だけ上である
- **SPEC-972** ハンドルを縦にドラッグすると、そのハンドルのゲインはポインタの y 位置に対応する値を 0.1 dB に丸め、±12 でクランプした値になる
- **SPEC-973** ハンドルを横方向に動かしても、ハンドルの x 位置とどの制御点かは変わらない
- **SPEC-974** 20 個のハンドルを結ぶゲイン線が描かれ、ドラッグ中もハンドルの位置に追従する
- **SPEC-975** ドラッグ中は、操作中の制御点の周波数とゲインが数値で表示される
- **SPEC-976** ゲインが変わると、最後の変更から 300ms 後に `envelope` が 1 回呼ばれ、その `params.curve` は画面上の 20 個のゲインと一致する
- **SPEC-977** 加工音の `synthesize` の `params.curve` は、画面上の 20 個のゲインと一致する
- **SPEC-978** ハンドルをダブルクリックすると、その制御点のゲインは 0 に戻る
- **SPEC-979** 「すべてリセット」とプリセットは、すべての制御点のゲインを 0 に戻す
- **SPEC-980** 分解前（グラフに包絡が無い状態）でもハンドルは表示され、ドラッグでゲインを設定できる

### 画面: モーフィング

- **SPEC-985** 「現在の録音」と「混ぜる相手」の 2 つの選択欄があり、分解済みの録音が分解した順に並ぶ。各項目のラベルは通し番号・入力元の表示名・長さ（秒）を含む
- **SPEC-986** 新しく分解が完了すると、その録音が両方の選択欄の末尾に追加され、「現在の録音」がそれに切り替わる
- **SPEC-987** 「現在の録音」を切り替えると、フレームスライダーの範囲と値、無声表示、グラフが切り替わり、以降の呼び出しと元音再生はその録音の id を使う
- **SPEC-988** 「混ぜる相手」の先頭は「なし」で初期値もそれであり、「なし」のとき `params` に `morph` は含まれない
- **SPEC-989** 混合比スライダー（name `mix`）の範囲は 0〜1、刻み 0.01、初期値 0 で、隣の数値表示が追従する
- **SPEC-990** 相手を選んでいるとき、`envelope` と `synthesize` の `params.morph` は `{ id: <相手の id>, ratio: <mix の値> }` である
- **SPEC-991** 相手の選択または mix の変更から 300ms 後に、`envelope` が 1 回呼ばれる
- **SPEC-992** 「すべてリセット」とプリセットは mix を 0 に戻し、「混ぜる相手」の選択は変えない
- **SPEC-993** mix スライダーをダブルクリックすると 0 に戻る
- **SPEC-994** 選択欄の録音は最新 10 件までで、11 件目が追加されると最も古いものが両方の選択欄から消え、それが相手に選ばれていた場合は「なし」になる

### 画面: 再生・比較

- **SPEC-1000** 加工音ボタンを押すと、その時点のスライダー値を `params` として `synthesize` が呼ばれ、返った音が先頭から再生される
- **SPEC-1001** `synthesize` の完了待ちの間、加工音ボタンはローディング表示になる
- **SPEC-1002** 元音ボタンを押すと、`original` が返す音が先頭から再生される
- **SPEC-1003** スペースキーを押すと、直前に再生したのが元音なら加工音を、加工音または未再生なら元音を先頭から再生する
- **SPEC-1004** スライダーやボタンにフォーカスがあってもスペースキーは A/B 切り替えとしてだけ働き、ボタン押下・ページスクロールは起きない
- **SPEC-1005** 新しく再生を始めると、再生中の音は停止する
- **SPEC-1006** 再生は WAV を作らずに行う（AudioBuffer から直接鳴らす）

### 画面: エラー表示とツールチップ

- **SPEC-1010** アダプタの呼び出しが拒否されたとき、エラー表示領域にメッセージが表示される
- **SPEC-1011** ページ読み込み直後、ツールチップは表示されていない
- **SPEC-1012** `data-tip` を持つ要素にポインタを合わせると、`data-tip` の文言がツールチップとして表示される
- **SPEC-1013** ポインタを外すとツールチップは消える
- **SPEC-1014** `data-tip` を持つ要素をキーボードでフォーカスするとツールチップが表示され、フォーカスが外れると消える
- **SPEC-1015** ツールチップが表示されている間に Escape キーを押すと消える
- **SPEC-1016** ツールチップはポインタ操作を受け取らず、下にある要素のクリック・ドラッグを妨げない
- **SPEC-1017** 8 つのパラメータスライダーと mix スライダーは、それぞれ声に何が起きるかを述べた空でない `data-tip` を持つ
- **SPEC-1018** 録音ボタン・ファイルを開くボタン・元音ボタン・加工音ボタン・現在の録音の選択欄・混ぜる相手の選択欄・フレームスライダー・すべてリセットボタン・各プリセットボタン・ゲインカーブの各制御点は、空でない `data-tip` を持つ
- **SPEC-1019** パラメータスライダー（8 つと mix）の `accent-color` は、値が初期値のときグレー（R = G = B）で、初期値と異なるときグレーでない強調色になる
- **SPEC-1020** ダブルクリック・すべてリセット・プリセットで初期値に戻ったスライダーは、`accent-color` がグレーに戻る
- **SPEC-1021** フレームスライダーの `accent-color` は、値によらず常にグレーである
- **SPEC-1022** 画面に出うる文言（本文・ラベル・選択欄・ツールチップ・そのとき非表示の要素の文言を含み、スクリプトとスタイルの中身は除く）に、大文字小文字を問わず `f0` という綴りが現れない
- **SPEC-1023** 分解の完了後、分解結果の表示は「平均 fo <`f0Mean` を小数 1 桁にした数値> Hz」をこの並びで含む

### 静的配信で動くこと

- **SPEC-1030** アプリは、静的ファイルを返すだけのサーバーから配信しても動く（サーバー側の処理を呼ばない）
- **SPEC-1031** アプリの読み込みから操作可能になるまでに、ネットワークへ出る要求は、アプリ自身のファイル（HTML / JS / WASM）だけである

## 非機能要件

測定条件: Apple M4 Max、Chromium（Playwright）、合成母音。

- **SPEC-1040** 3 秒の音声の `analyze` が、呼び出しから完了まで 3.0 秒未満である
- **SPEC-1041** つまみを動かしてからグラフが更新されるまで（デバウンス 300ms を含み、相手の伸縮も含む）が 1.0 秒未満である
- **SPEC-1042** 3 秒の音声の `synthesize` が、呼び出しから完了まで 1.0 秒未満である
- **SPEC-1043** `benchmarks/browser-app/` に、上記 3 つの中央値の基準値と、計測に使ったコマンドがある

## 受け入れ試聴（仕様外・人が判定）

テストで真偽を判定できないため仕様IDは振らない。結果は `verification.md` に記録する。
v0.1.0 の M1〜M3 と同じ観点を、ブラウザ版で確かめる。

- M1: 実際の声で、元音と無加工再合成音の声質の差が聴き分けられない
- M2: 母音を変えて録音すると、グラフのピーク位置が明らかに変わる
- M3: formant スライダーを動かすと、グラフのピークが左右に動き、再生音の声質も同じ方向に変わる

## 前提・依存

- 006 のエンジンと 007 の DSP を使う。分析条件は 44100Hz / fft_size 2048 / frame_period 5ms で固定
- 録音は `MediaRecorder`、デコードは `decodeAudioData` と `OfflineAudioContext`、再生は `AudioBuffer` を使う
- E2E は Playwright の Chromium と偽マイク入力で行う（v0.1.0 と同じ）
- **入力の数値は v0.1.0 と一致しない**（ADR-0001 の影響に記載のとおり）。ffmpeg 版は 16bit に量子化していたが、ブラウザ版は Float32 のままで、リサンプリングの実装もブラウザごとに違う
- Safari と iOS は動作を保証しない（ADR-0001 の追記）
