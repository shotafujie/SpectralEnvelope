# テスト設計書: 説明のツールチップ化とスライダーの変更表示

- アイテムID: `005-ui-affordance`
- 仕様書: `docs/items/005-ui-affordance/spec.md`
- 作成日: 2026-09-18

## テスト方針

- すべて E2E（`tests/e2e/test_tooltip.py`）。実サーバー + Playwright Chromium
- 観測点: `#tooltip`（ツールチップ本体）、各要素の `data-tip` 属性、`accent-color`（`getComputedStyle`）
- 色の判定は `accent-color` の計算値を RGB に分解し、R = G = B ならグレーとする

## テストケース

### SPEC-600 初期状態

- **TC-600-1** ページ読み込み直後 → `#tooltip` が非表示

### SPEC-601 ポインタで表示

- **TC-601-1** formant スライダーにポインタを合わせる → `#tooltip` が表示され、文言がその要素の `data-tip` と一致
- **TC-601-2** 続けて pitch スライダーに合わせる → 文言が pitch の `data-tip` に変わる

### SPEC-602 ポインタを外すと消える

- **TC-602-1** formant に合わせた後、説明の無い場所（見出し）へ動かす → `#tooltip` が非表示

### SPEC-603 キーボードでも表示

- **TC-603-1** 録音ボタンをフォーカス → `#tooltip` が表示され、文言が録音ボタンの `data-tip` と一致
- **TC-603-2** 別のフォーカスへ移す → `#tooltip` が非表示

### SPEC-604 Escape で消える

- **TC-604-1** formant に合わせて表示させた後 Escape → `#tooltip` が非表示

### SPEC-605 ツールチップは操作を妨げない

- **TC-605-1** `#tooltip` の `pointer-events` が `none`
- **TC-605-2** ゲインカーブの制御点にポインタを合わせてツールチップを出した状態からドラッグ → ゲインが変わる

### SPEC-606 旧ヒントは常時表示されない

- **TC-606-1** ページ読み込み直後 → 「交互に再生」「ダブルクリックで初期値」「比率で混ぜる」を文字列として含む可視要素が無い（「混ぜる相手」のような操作のラベルは対象外）
- **TC-606-2** 加工音ボタン・formant スライダー・mix スライダーの `data-tip` が、それぞれ「交互に再生」「ダブルクリックで初期値」「比率で混ぜる」を含む

### SPEC-607 パラメータの説明

- **TC-607-1** 9 つのスライダー（formant / tilt / band0〜3 / smooth / pitch / mix）すべてが 5 文字以上の `data-tip` を持ち、互いに異なる

### SPEC-608 主要な操作の説明

- **TC-608-1** `#rec` / `#open-file` / `#play-orig` / `#play-mod` / `#current` / `#partner` / `#frame` / `#reset` が空でない `data-tip` を持つ
- **TC-608-2** プリセット 5 ボタンと制御点 20 個がすべて空でない `data-tip` を持つ

### SPEC-614 画面に f0 の綴りが出ない

- **TC-614-1** 録音して分解した後 → ページ内の全要素のテキスト（`script` / `style` を除き、`hidden` の要素も含む）と全 `data-tip` 属性に、大文字小文字を問わず `f0` が無い
- **TC-614-2** 分解前のページ → 同上
- **TC-614-3** 無声フレームの表示・ゲインカーブのドラッグ中の表示・API エラーの表示を出した状態 → いずれも `f0` を含まない

### SPEC-615 分解結果の表示

- **TC-615-1** 録音して分解した後 → 分解結果の表示が、正規表現 `平均 fo <値> Hz`（値は応答の `f0_mean` を小数 1 桁にしたもの）にこの並びで一致する

### SPEC-610 初期値はグレー

- **TC-610-1** ページ読み込み直後 → 9 つのスライダーすべての `accent-color` がグレー（R = G = B）

### SPEC-611 変更すると色が付く

- **TC-611-1** formant を 1.3 にする → formant の `accent-color` がグレーでなく、他の 8 つはグレーのまま
- **TC-611-2** mix を 0.5 にする → mix の `accent-color` がグレーでない

### SPEC-612 戻すとグレーに戻る

- **TC-612-1** tilt を 5 にしてダブルクリック → グレーに戻る
- **TC-612-2** 複数を変更して「すべてリセット」→ 9 つすべてグレー
- **TC-612-3** プリセット「子供っぽく」→ formant と pitch がグレーでなく、他はグレー

### SPEC-613 フレームスライダーは常にグレー

- **TC-613-1** 分解後にフレームスライダーを動かす → `accent-color` がグレー
