# 仕様書: 説明のツールチップ化とスライダーの変更表示

- アイテムID: `005-ui-affordance`
- 関連ロードマップ項目: なし
- 関連ADR: なし
- 作成日: 2026-09-18
- 前提: `001-envelope-jig`〜`004-gain-curve` の UI

## 目的

画面に常時出ている説明文を消してグラフと操作に集中できるようにし、説明はポインタを合わせたときだけ出す。
あわせて、どのパラメータを初期値から動かしたかが一目で分かるようにする。

## スコープ

### やらないこと

- 説明文の常時表示に戻す設定
- コード側の名前（pyworld の識別子、API の応答フィールド `f0_mean`）の変更
- ツールチップの位置の手動調整、複数行の書式指定、マークダウン
- タッチ操作での表示（ポインタとキーボードのみ）
- 凡例（元の包絡・加工後・混ぜる相手・ゲインカーブ）の削除。凡例は色の対応表なので残す

### やること

- `data-tip` を持つ要素のツールチップ表示
- 画面の常時表示の説明文の削除と、説明のツールチップへの移動
- 各パラメータが声に何をするかの説明の追加
- パラメータスライダーの色を、初期値かどうかで切り替える

## 仕様

### ツールチップ

- **SPEC-600** ページ読み込み直後、ツールチップは表示されていない
- **SPEC-601** `data-tip` を持つ要素にポインタを合わせると、`data-tip` の文言がツールチップとして表示される
- **SPEC-602** ポインタを外すとツールチップは消える
- **SPEC-603** `data-tip` を持つ要素をキーボードでフォーカスするとツールチップが表示され、フォーカスが外れると消える
- **SPEC-604** ツールチップが表示されている間に Escape キーを押すと消える
- **SPEC-605** ツールチップはポインタ操作を受け取らず、下にある要素のクリック・ドラッグを妨げない
- **SPEC-606** 以前ヒントとして画面に常時表示していた 3 つの説明（Space での A/B 切り替え、スライダーのダブルクリック、mix の混合）は、初期表示では見えず、対応する要素のツールチップとしてのみ見える
- **SPEC-607** 8 つのパラメータスライダー（formant / tilt / bands×4 / smooth / pitch）と mix スライダーは、それぞれ声に何が起きるかを述べた空でない `data-tip` を持つ
- **SPEC-608** 録音ボタン・ファイルを開くボタン・元音ボタン・加工音ボタン・現在の録音の選択欄・混ぜる相手の選択欄・フレームスライダー・すべてリセットボタン・各プリセットボタン・ゲインカーブの各制御点は、空でない `data-tip` を持つ

### 基本周波数の表記

- **SPEC-614** 画面に出うる文言（本文・ラベル・選択欄・ツールチップ・そのとき非表示の要素の文言を含み、スクリプトとスタイルの中身は除く）に、大文字小文字を問わず `f0` という綴りが現れない
- **SPEC-615** 分解の完了後、分解結果の表示は「平均 fo <`f0_mean` を小数 1 桁にした数値> Hz」をこの並びで含む

### スライダーの変更表示

- **SPEC-610** パラメータスライダー（8 つと mix）の `accent-color` は、値が初期値のときグレー（R = G = B）である
- **SPEC-611** 値が初期値と異なるとき、`accent-color` はグレーでない強調色になる
- **SPEC-612** ダブルクリック・すべてリセット・プリセットで初期値に戻ったスライダーは、`accent-color` がグレーに戻る
- **SPEC-613** フレームスライダーの `accent-color` は、値によらず常にグレーである
